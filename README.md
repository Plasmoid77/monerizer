# Monerizer

Проект локального CLI/TUI для эксплуатации P2Pool + XMRig на Linux с systemd.

Состояние: проектирование. Приложение пока не реализовано.

- [Техническое задание v1](docs/superpowers/specs/2026-09-11-monerizer-design.md) — границы продукта, архитектура, команды, права, обработка сбоев и приёмка.
- [План реализации](docs/superpowers/plans/2026-09-11-monerizer-implementation.md) — этапы, пакеты, стенд, fixtures, решения владельца.
- [Проверенные upstream-контракты](docs/research/upstream-contracts.md) — источники показателей, единицы, ограничения и условия совместимости.
- [Отчёт стенда №1](docs/research/stand-report-1.md) — пара P2Pool 4.18 + XMRig 6.26.0 запущена от пользователя; реальные fixtures в `testdata/`.
- [Отчёт стенда №2](docs/research/stand-report-2.md) — та же пара под systemd; `systemd/` и `examples/` проверены на стенде.
- [Исходный handoff](xmrig-p2pool-tui-ai-handoff-v2.md) — первоначальное исследование; решения в ТЗ имеют приоритет после его согласования.

Согласованный первый запуск: готовые нативные конфиги, systemd-шаблоны и точная инструкция. Мастер установки отложен.

Рабочая директория проекта — `/home/plasmoid/Monerizer`. Установка служб, запуск майнинга и изменения системных настроек при подготовке документации не выполняются.
